# 第██次收容

**Containment Attempt #██ · Prototype 0.2（配置拆分）**

Godot 4.7 项目。当前是单角色、单层设施的可玩原型代码，美术采用程序绘制的临时图形，音效为程序合成。

## 打开项目

在 Godot 中导入本目录的 `project.godot`，打开后按 **F6** 运行当前场景，或按 **F5** 运行整个项目。主场景已设置为 `main.tscn`。

流程：主界面 → 开始游戏 → 选人 → 以回收员开始收容。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 冲刺 | 空格；按最近的移动方向冲刺，冲刺期间无敌 |
| 攻击 | 自动瞄准射程内最近的敌人 |
| 打开补给终端 | 在补给房按 E；首次进入自动打开 |
| 暂停 / 继续 | Esc |
| 过图 | 走近开放的门口 |

## 当前单局

- 4 × 3 连通房间；起点、8 间战斗房、1 间补给房、1 间奖励房、1 间核心房。
- 战斗房封锁出口，包含两波异常体；清空后获得零件与三选一强化。
- 初版敌人有追击、重型和远程三种，核心敌人有弹幕和预警冲刺。
- 清除至少 4 间战斗房后，核心门禁解除。击败核心即可通关，也可以先探索其余房间。
- 房间清除状态和探索奖励领取状态在本局保留；回访不会重复刷怪或发放免费奖励。
- 小地图显示已访问的房间及相邻区域，不直接揭示全部房型。
- 零件靠近时自动吸取；战斗清空或离开房间时自动回收未拾取的零件。
- 补给站提供 3 个随机强化、付费刷新和一次医疗。刷新费用逐次增加。
- 强化包括伤害、射速、弹数、穿透、生命、防御、移动与回收范围。
- 死亡或通关都有结算页，可立即再开一局或重新选人。

目标体验约 5–10 分钟，尚未通过试玩确认时长和难度。

## 暂不包含

局外成长仅有占位页面，暂不保存资源或提供永久加成。其余角色未开放。地图形状和特殊房位置目前固定，敌人位置、强化选择和补给物资随机。尚无多层地图、存档、手柄操作或正式美术。

## 文件

- `project.godot`：引擎配置与主场景入口，使用 Compatibility 渲染。
- `main.tscn`：主场景。
- `main.gd`：菜单、房间流程、战斗、奖励、补给、结算与临时表现。
- `run_data.gd`：基础属性、强化配置与强化应用规则。
- `work/project-original.godot`：接入代码之前的原项目配置备份。

新增配置入口位于 `configs/`；具体字段、编号引用和扩展步骤见 [配置编辑指南](configs/README.md)。角色、武器品类、武器、属性、强化、奖励/奖励池、怪物、收容物、房型、楼层和全局参数已拆分，当前循环读取这些数据。`scripts/config_database.gd` 负责读取和校验，`run_data.gd` 负责属性合成及抽取规则。

默认奖励池延续原版八种强化。武器和被动收容物奖励已支持，但示例尚未加入默认池；可以通过配置决定何时出现。角色超过三名时支持选人分页。

后续局外成长应在开始新局前统一应用基础属性增量，并单独保存局外数据；本次尚未接入。
